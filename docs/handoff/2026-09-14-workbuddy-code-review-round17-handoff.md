### P3-2（低）T-1 收盘保留 77~79 根被错误归因于「`n` 达到 241/243 根」，复算后该分支恒为 80 根

- **文件与行号**（2 处，同源同述）：
  - `…limit-up-chart-date-flip-investigation-and-resolution-handoff.md:71`（§2.2 第 3 点，T-1 条目）：「……收盘 $x=240$ 时仍有 80 根，全天随 $x$ 递减并保持在 80~240 根；**若 T-1 或当日计入集合竞价点使 $n$ 或 $x$ 达到 241/243 根，则收盘保留约 77~79 根**」；

  - 期望（文档文字）：`n` 达到 241/243 时，T-1 收盘保留根数降为 `77~79`。

- **影响范围**：仅影响根因章/结论章的量化严谨性（无产品代码/测试改动，无运行期影响）。`:71` 与 `:135` 是「T-1 全程保有伪分时素材」的数值论据；按现文本，读者会得出「T-1 自身为 243 根/日时收盘仅余 77 根」的错误定量结论（实际恒 80 根），并把它当成 T-1/T-2 覆盖差异的一部分。主线结论（T-1 恒在覆盖带内、T-2 于 `x ≥ 320-n` 后滑出）不受影响。
- **复现方法/验证证据**（同一仓库外探针 `%TEMP%/r17probe/window.mjs`，未入库）：

   x=240 (close, today normal 240): n=240 -> T-1 retained = 80
   x=240 (close, today normal 240): n=241 -> T-1 retained = 80
   x=240 (close, today normal 240): n=243 -> T-1 retained = 80

  （对照行说明 T-2 侧的 `n` 依赖为真、`doc:68` 无误；失效仅出现在 T-1 侧的两处复述。）

- **修复后验收标准**：`:71`/`:135` 中 T-1 收盘保留根数的每个取值分支，均可在 `n ∈ {240,241,243}` 下由 `min(n, 320-x)` 复算得出（`x=240` → 80 与 `n` 无关；`x=241/243` → 79/77）；不存在未带条件地把 `77~79` 归因于 `n` 的表述。
