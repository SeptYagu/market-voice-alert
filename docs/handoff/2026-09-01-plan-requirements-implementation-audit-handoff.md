## 2. 审查口径

- **已实现**：源码存在完整执行链路，并能找到单测、E2E 或本轮运行证据。
- **部分实现**：主体功能存在，但有明确子项缺失，或承诺只有代码、缺直接验收证据。
- **未实现**：当前源码明确不支持，或找不到执行链路。
- **已替代/不适用**：需求源已标注过时，或后续 handoff 记录了用户确认的新交互；不进入完成率分母。
- 计划完成率按唯一的可执行 Task/Phase 计数，不把同一内容的“设计文档 + 实施文档”重复计算。
- `SPEC.md` 核心完成率按 §3.1-§3.6 和 §5.4 中仍有效的功能行计数；历史数据源、历史技术选型和旧目录结构不进入分母。
