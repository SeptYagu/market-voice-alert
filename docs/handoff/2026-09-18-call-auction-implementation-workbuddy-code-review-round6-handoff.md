- **实际行为**（真实模块 `applyLiveQuoteToKline` 实跑，`_audit_r6/probe.mjs` §P5）：


- **期望行为**：`quoteTimeMinutes === null`（时效无法证明）时不得清除 `preview`、不得让当日柱 `high/low` 由盘前虚拟价驱动 —— 内容证据只能作为**受时效约束且能自证「获得新信息」**的升级通道。R5 §二 P2-1 的「期望行为」与「修复建议 2」原文即要求该通道为「`volume > 0` **且** `price !== preview 价` **且** 客户端时钟 ≥ 09:30」三者合取，并在注释中明确残余风险；本轮实现只取了「volume > 0 + 时钟 ≥ 09:30」两项。

- **影响范围**：A 股 `1d` 当日 `low/high/open` 可被集合竞价虚拟价写死并持续整个交易日（官方 K 线仅在展开/切周期/强制刷新时重载，全仓无周期重载）；与验收标准 1「日K集合竞价下影线**彻底**消除」直接冲突，且 R5 P2-1 的「期望行为」字面未达成。非 A 股与分钟/周/月周期不受影响。
- **复现方法 / 运行证据**：
