# 涨停看板（独立页面）

> 股票期货监控助手 v2 新增功能 — 一键浏览全市场涨停股票

## 1. 功能概览

涨停看板是监控助手的独立 SPA 页面，专注于**实时显示全市场涨停股票**。与监控页（自选股管理）并列，通过顶部导航切换。

**核心特性**：
- 🚀 **实时刷新**：可调频率（10/30/60 秒），后台拉取东财涨停池
- 📊 **4 个分组**：3+ 连板 / 2 连板 / 1 连板 / 炸板，一目了然
- 🔍 **4 种排序**：连板数 / 涨跌幅 / 封板时间 / 成交金额
- ☑️ **批量加入**：复选框多选 → 一键加入监控列表
- 📈 **行内 K 线**：点行直接展开 K 线（不跳转）
- 🌙 **非交易时段友好**：空响应锁定 + 状态栏时间戳提示

> 📷 **截图位**：看板主界面（首页推荐位 1）

## 3. 排序选项

工具栏的"排序"下拉切换视图顺序。**桶内排序**（不影响分组归属）：

| 选项 | 排序键 | 适用场景 |
|------|--------|----------|
| **连板数** | `limitUpCount desc` → 涨跌幅 desc → 代码 asc | 默认；找热门连板股 |
| **涨幅** | `changePercent desc` → 连板数 desc → 代码 asc | 找涨幅最高（含炸板回弹） |
| **封板时间** | `firstLimitTime asc` → 涨跌幅 desc → 代码 asc | 找早盘强势股 |
| **成交金额** | `amount desc` → 连板数 desc → 代码 asc | 找资金流入 |

排序选项**自动保存**到 localStorage（仅刷新频率持久化，排序切换不持久化以保持默认）。

## 4. 批量加入监控

适合从看板"看到好股 → 批量加入监控列表"的工作流：

1. 勾选每行前面的 **☐ 复选框**
2. 右上角计数器显示 `N 已选`
3. 点击 **➕ 添加选中** 按钮 → 自动跳到监控页 (`#/`)
4. 监控列表出现刚选中的所有股票 + 状态栏提示"已加入监控 N 只"

辅助链接：
- **全选**：选中所有展示行（不含炸板桶？）
- **取消全选**：清空所有勾选

去重：已存在的标的不会重复添加（计数器包含但加入时静默去重）。

## 5. 行内 K 线

点行（除 checkbox / 按钮）→ K 线图在**该行下方**内嵌展开：

```
│   ☐ sh600519 贵州茅台  ST  3板 ¥1850 +10.01% │  ← 数据行
├────────────────────────────────────────┤  ← K 线行（colspan=8）
│   [贵州茅台] [sh600519]                 │  ← 标题 + 关闭
│   [日K] [周K] [月K] [1分] [5分] [15分]   │  ← 周期 tab
│   日K · 30 根                            │  ← 状态
│   ┌──────────────────────────────────┐  │
│   │       [K 线主图]                  │  │  ← chart host
│   │   [成交量]                        │  │
│   └──────────────────────────────────┘  │
```

**操作**：
- 切换周期 tab → 重新拉取该周期 K 线
- 关闭按钮（× 关闭）→ 折叠 K 线
- 再次点行 → 关闭 K 线
- 缩放/拖动 → 实时刷新时**保留状态**（series.update 而非 setData+fitContent）

监控页和看板页**共享同一份 K 线图实现**（创建/销毁独立，互不干扰）。

## 6. 非交易时段行为

**东财 clist/get 在以下时段可能返回 `data.diff: []`**：
- 盘前（9:00 前）
- 午休（11:30-13:00）
- 盘后（15:00 后）
- 节假日
- 数据源静默（凌晨偶尔 502）

**看板不会立刻变空**，而是**锁定显示最近一次非空快照**，状态栏追加提示：

```
共 38 只涨停 · 缓存自 14:35:22 · 已空 1 次
```

多次空响应 → `已空 N 次` 递增，给用户清晰信号"数据源静默"vs"真无涨停"。

实时价合并**继续工作**（监控 timer 在后台跑，state.quotes 持续更新）→ 看板中股票的最新价/涨跌幅会持续刷新，但**连板数/封板时间等 metadata 不变**（这些只在 clist/get 拉取时更新）。

## 7. 常见问题

### Q1: 名字显示乱码？
A: 浏览器可能缓存了旧版本代码。按 `Ctrl+Shift+R` 强制刷新清缓存。如问题持续，检查浏览器编码设置（应自动）。

### Q2: 为什么连板数/封板时间/炸板次数一直是 0/null/0？
A: 这些 metadata 需要调用额外的 per-stock API（`/api/limit-up-stock`）。东财 clist/get 的 f100/f102/f103 字段实际是**行业/概念字符串**，不是 metadata。当前实现是 **best-effort**，未来可通过 AKTools 后端代理升级。

### Q3: 空响应时为什么数据不更新？
A: 故意设计为"锁定显示"。避免非交易时段看板空白让用户误以为"今日无涨停"。状态栏明确显示缓存时间和已空次数。

### Q4: 行点击后没跳转？
A: 看板行点击 = 展开行内 K 线（不跳转）。要"加入监控 + 跳转"请用复选框 + "➕ 添加选中"按钮。

### Q5: 多只股票 K 线图能同时展开吗？
A: 监控页支持（多 K 线图，每只股票独立 chart instance）。看板页当前只支持一只股票 K 线展开（再点另一只切换）。
