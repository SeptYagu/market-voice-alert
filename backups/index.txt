## 使用方法

### 查看备份

```bash
ls backups/
```

### 恢复备份

```bash
# 恢复到最后备份
./scripts/restore.sh phase2_start

# 恢复指定备份
./scripts/restore.sh [备份名称]
```

### 创建备份

```bash
# 手动备份
./scripts/backup.sh phase2_mid

# 自动备份会在每次Phase开始时提示
```

---

## 备份策略

1. **阶段开始时**: 自动提示创建备份
2. **每天**: 自动创建每日备份
3. **重大修改前**: 手动创建备份

### 保留规则

- 阶段备份: 永久保留
- 每日备份: 保留30天
